As part of our accessibility statement, we would like to provide you with an overview of the compatibility status of the service(s) described below with accessibility requirements according to legal regulations (in particular with the Barrier-Free Strengthening Act / “Barrierefreiheitsstärkungsgesetz – BFSG”).

General Description of Service

Documentation of the Linux window manager LCARSDE.

Service Implementation Details

Through lcarsde.github.io, we provide publicly accessible and free documentation for the Open Source Software LCARSDE.

Compliance Status with Requirements

The above-mentioned service is fully compliant with the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA and the Barrier-Free Strengthening Act (BFSG).

The following measures were taken to ensure accessibility:

  • All text meets WCAG AA contrast ratios (4.5:1 for normal text, 3:1 for large text)
  • All interactive elements are keyboard accessible with visible focus indicators
  • Content remains visible and usable when JavaScript is unavailable
  • Responsive layouts use correct semantic markup for assistive technologies
  • Dark mode theming respects the Starlight theme toggle rather than relying solely on OS-level preference
  • Automated accessibility testing using axe-core is part of the continuous integration pipeline
  • Creation of Accessibility Statement
  • Date of creation of an accessibility statement: 07.10.2025
  • Date of last review of the above services regarding accessibility requirements: 15.04.2026

Assessment of Accessibility Status

The assessment of accessibility status is based on our self-assessment, supplemented by automated testing with axe-core (WCAG 2.1 AA ruleset).
